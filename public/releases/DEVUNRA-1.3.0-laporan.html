Perbaikan yang selesai di source

Startup menampilkan jendela loading dahulu. Pemeriksaan seluruh checksum, inventaris, dan arsitektur berjalan di worker; supervisor dan engine baru tersedia setelah verifikasi berhasil. Ini mengatasi aplikasi yang terlihat belum terbuka saat validasi payload besar.

Pada diagnosis Windows, jendela tampil 121 ms, bundle selesai diverifikasi 15.616 ms, supervisor siap 16.256 ms, dan dashboard selesai 16.431 ms. Angka 121 ms adalah waktu tampil jendela loading, bukan waktu dashboard siap.

phpMyAdmin dipatok ke arsip resmi 5.2.3 yang diverifikasi ukuran dan SHA-256 serta dibundel agar pemasangan awal dapat memakai resource lokal. Jaringan runner tidak dinonaktifkan, sehingga run ini tidak membuktikan seluruh alur pada perangkat terputus internet. Login dan navigasi database nyata pada PHP Windows 8.5.12 lulus tanpa Deprecated, Warning, Fatal, atau Parse; diagnostic PHP tidak disembunyikan secara global.

Start All menunggu inisialisasi layanan nyata selesai. Pergantian PHP menuntaskan perubahan pool/port sebelum satu reload web. Laravel dan WordPress menunggu pemasangan selesai lalu memeriksa konfigurasi database serta respons HTTP. Path kanonik Windows dan konfigurasi PHP child Composer juga telah diperbaiki.

Memcached dihapus sesuai permintaan. Produk mempunyai Apache, PHP, MySQL, PostgreSQL, Redis, Nginx, dan MongoDB, ditambah mail catcher. Profil/state lama memfilter ID Memcached tanpa menghapus data lama atau menyalakannya otomatis. Redis tetap pada port 16379; port pengguna lain tetap dipertahankan.

Kebutuhan sistem

Paket Windows lengkap 1.3.0 ditujukan untuk Windows 11 x64 atau Windows Server 2022 x64 dan yang lebih baru, dengan batas kernel 10.0.20348 dari payload yang disertakan. Paket ini memerlukan Microsoft Visual C++ 2015–2022 x64 runtime serta dukungan WoW64 untuk distribusi Nginx Win32 resmi. Dukungan Windows 10 umum tidak diklaim untuk payload lengkap ini.

Signing dan notarisasi dikecualikan sesuai instruksi pengguna. Rilis Mac tetap 1.2.0; laporan ini tidak mengklaim paket Mac 1.3.0.

Windows 1.3.0 disiapkan untuk unduhan manual dari halaman web. Feed pembaruan otomatis tetap 1.2.0; karena itu feed tersebut belum menawarkan pembaruan otomatis ke Windows 1.3.0. Label dan tautan Mac tetap 1.2.0.
