Laporan verifikasi 1.2.0

Rilis Mac terverifikasi · Windows dalam perbaikan

DEVUNRA 1.2.0 menambahkan engine Nginx, MongoDB, dan Memcached asli pada macOS, paket engine yang diperiksa sebelum dijalankan, paket Intel x64, serta pemeriksaan versi dan unduhan installer terverifikasi.

Tes yang dilewati tidak dihitung lulus. Kelompok tes saling mencakup sebagian perilaku, sehingga angkanya tidak dijumlahkan menjadi satu total. Tes Intel melalui Rosetta tidak membuktikan hasil pada Mac Intel fisik; Windows VM juga tidak membuktikan semua perangkat Windows.

Pemasangan pada Mac pengguna

Aplikasi telah diperbarui menjadi 1.2.0 dari installer terverifikasi. Enam layanan yang sebelumnya aktif kembali berjalan pada port yang sama. Pengaturan, tiga profil tersimpan, pengaturan PHP, seluruh port layanan dan dua port HTTPS tetap sama. Delapan pemeriksaan baca-saja lulus; dua database pengguna MySQL masih dapat diakses. Isi database yang sedang berjalan tidak dibandingkan byte demi byte. App lokal terbuka tanpa dialog karena atribut karantina tidak ada; unduhan browser baru masih dapat memunculkan peringatan Gatekeeper.

Isi paket dan kebutuhan sistem

Paket Apple Silicon lengkap menyertakan Apache 2.4.69, Nginx 1.31.8, PHP 8.5.12, MySQL 9.6.0, PostgreSQL 16.15, MongoDB 8.0.34, Redis 8.4.0, dan Memcached 1.6.45. Paket lengkap membutuhkan macOS 27.0 atau lebih baru berdasarkan seluruh binary dan pustakanya.

Paket slim Apple Silicon dan Intel berisi aplikasi dengan kebutuhan macOS 11.0 atau lebih baru. Engine perlu dipasang sendiri sesuai OS. Paket lengkap menyertakan satu versi PHP; perpindahan versi dan PHP per situs diuji pada tes source yang mempunyai beberapa versi PHP.

Batas yang perlu diketahui

Port tetap sesuai pengaturan sebelumnya. Signing dan notarisasi dilewati sesuai permintaan. Pembaruan menyediakan pemeriksaan versi dan unduhan installer dengan verifikasi ukuran serta SHA-256; pengguna menutup aplikasi dan memasang installer secara manual.

Feed Apple Silicon menyediakan paket lengkap macOS 27.0+ agar penggantian aplikasi tidak menghilangkan engine yang disertakan. Pengguna macOS lebih lama memilih installer slim dari web. Memcached upstream tidak menyediakan build Windows resmi.

Angka memori idle dan perbandingan kinerja terhadap Laragon atau XAMPP tidak diukur ulang pada pekerjaan ini.
