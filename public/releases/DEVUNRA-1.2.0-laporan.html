Perubahan yang selesai

DEVUNRA 1.2.0 menyediakan delapan engine asli dalam paket lengkap Apple Silicon dan lima layanan inti dalam paket Windows. Port tetap sesuai permintaan. Panduan membuka aplikasi di macOS telah diperbaiki, dan pembaruan menyediakan pemeriksaan versi serta unduhan installer terverifikasi.

Paket Mac lengkap menyertakan Apache 2.4.69, Nginx 1.31.8, PHP 8.5.12, MySQL 9.6.0, PostgreSQL 16.15, MongoDB 8.0.34, Redis 8.4.0, dan Memcached 1.6.45. Windows menyertakan Apache, PHP, MySQL, PostgreSQL, dan Redis. Nginx, MongoDB, dan Memcached pada Windows masih memakai simulasi.

Server PostgreSQL Windows, alat client, pustaka, data pendukung, dan lisensinya tetap disertakan. Aplikasi administrasi pgAdmin 4 yang terpisah tidak disertakan. Seluruh isi engine tetap diperiksa melalui manifest dan SHA-256 sebelum dijalankan.

Hasil dan batas pengujian

Tes yang dilewati tidak dihitung lulus. Kelompok tes saling mencakup sebagian perilaku dan tidak dijumlahkan menjadi satu total. Paket lengkap menyertakan satu versi PHP; perpindahan versi dan PHP per situs diuji pada tes source yang mempunyai beberapa versi PHP.

Windows diuji pada VM Windows Server 2022 yang sudah memiliki Microsoft Visual C++ x64 runtime. Perangkat Windows fisik dan pemasangan pada OS bersih tanpa runtime tersebut belum diuji. Intel diuji melalui Rosetta pada Apple Silicon, belum pada Mac Intel fisik.

Percobaan Windows sebelumnya menemukan masalah pemasangan, isi paket pgAdmin, reset konfigurasi saat berkas dikunci sementara, dan kesiapan HTTPS. Hasil gagal tetap tersimpan sebagai riwayat diagnostik dalam data pengujian. Status akhir pada laporan ini hanya mengacu pada EXE dan ZIP final dengan identitas yang dicantumkan.

Pemasangan pada Mac pengguna

Aplikasi Mac telah diperbarui ke 1.2.0 dari installer terverifikasi. Enam layanan yang sebelumnya aktif kembali berjalan pada port yang sama. Pengaturan, tiga profil tersimpan, pengaturan PHP, semua port layanan, dan dua port HTTPS tetap sama. Delapan pemeriksaan baca-saja lulus; dua database MySQL pengguna masih dapat diakses. Isi database yang sedang berjalan tidak dibandingkan byte demi byte.

Cek pembaruan manual pada aplikasi Mac terpasang berhasil membaca feed live dan menyatakan versi 1.2.0 sudah terbaru. Tidak ada unduhan atau pemasangan pada tes tersebut; enam layanan tetap berjalan dengan PID dan port yang sama. App lokal terbuka tanpa dialog karena atribut karantina tidak ada; unduhan browser baru masih dapat memunculkan Gatekeeper.

Kebutuhan sistem dan pembaruan

Paket Apple Silicon lengkap membutuhkan macOS 27.0+ berdasarkan seluruh binary dan pustaka yang disertakan. Paket slim Apple Silicon dan Intel membutuhkan macOS 11.0+ dan tidak menyertakan engine; engine perlu dipasang sendiri sesuai OS. Windows membutuhkan Windows 10 x64 atau lebih baru serta Microsoft Visual C++ 2015–2022 x64 runtime.

Signing dan notarisasi dilewati sesuai permintaan. Unduhan baru masih dapat memunculkan Gatekeeper atau SmartScreen. Pembaruan memeriksa versi serta memverifikasi ukuran dan SHA-256 unduhan. Pengguna menutup aplikasi dan memasang installer secara manual; installer tidak dijalankan otomatis.

Feed Apple Silicon menyediakan paket lengkap macOS 27.0+ agar pembaruan tidak menghilangkan engine yang disertakan. Pengguna macOS lebih lama memilih paket slim dari web. Feed Intel menyediakan slim, dan feed Windows menyediakan installer EXE; ZIP dipilih manual dari web.

Identitas source dan hosting

Paket Mac yang telah diterima dipertahankan utuh. Sidik 50 berkas source terkompilasi dan aset Mac: 06da90ac214119363ed3c5e3fcbdb37fc70507eb977ce4f29b1ce0836d5488de. Paket Windows memakai source lebih baru e4bfab42cd26b3f87e0c7c5e90c855732406f6f7; perbaikan Windows terbaru tidak diklaim ada pada paket Mac yang lebih lama.

Website berada di server yang sama dengan Arsinode. Installer disimpan di GitHub Releases; server website menyimpan halaman dan metadata kecil. Source desktop tetap privat. Angka memori idle serta perbandingan kinerja terhadap Laragon atau XAMPP tidak diukur ulang pada pekerjaan ini.
